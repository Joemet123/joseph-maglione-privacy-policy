# Privacy policies

One folder per app, each serving `index.html` at `/<app>/`. Published by
GitHub Pages from `main` at the repo root, under the `joemet123.com` custom
domain set on `joemet123.github.io`.

**There is deliberately no index of the apps.** The root page and `404.html`
name no app and link to no folder, so a policy is reachable only by its own
address — the one in the app's App Store listing. GitHub Pages never
generates directory listings, so adding a folder does not expose it.

Note that this repository is public, so the folder names are visible to
anyone who opens the repo on github.com. Only the published website hides
them.

Adding an app: create `/<app>/index.html`, then use
`https://joemet123.com/joseph-maglione-privacy-policy/<app>/` as the privacy
policy URL wherever it is asked for. Change nothing at the root.
